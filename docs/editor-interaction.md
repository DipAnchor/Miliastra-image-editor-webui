# 多选、鼠标与快捷键

[返回使用指南](README.md)

## 选择图元

- **单选**：直接点图元或图层。
- **增选／减选**：画布上按 Shift 或 Ctrl/⌘ 点选。
- **连续选择**：图层列表按 Shift 点选，以最近单击的图层为起点；Ctrl/⌘ 切换单项。
- **框选**：在空白处拖框，碰到图元范围即选中；按 Shift/Ctrl/⌘ 可追加。
- **选择分组**：点击分组会同时选中组内全部元素（含嵌套子组）；Ctrl/⌘ 或 Shift 点组可增选／减选，也可与单独图层混选。右键已选项保留当前混合选择。
- **取消**：点空白处或按 Escape。拖动途中按 Escape 会恢复操作前状态。

透明或被蒙版裁掉的内容仍可选择。多选显示整体虚线边框；拖动任一已选图元可整体移动，Alt 拖动会复制整个选择。单图元继续使用原来的缩放和旋转手柄。

## 成组、锁定与层级拖动

- **成组**：在图层面板底部点「成组」，或在图层／分组右键菜单点「编组」。选择多个组或组＋图层时，新建一个组收纳所选项，原组及其子组结构保留；新组放在最近共同祖先内。成组后选中新组，可一步撤销／重做。
- **锁定其他**：保留所选图层、所选组及其全部后代，以及必要的祖先组；锁定其它项，不会因锁住祖先而间接锁住自己。已有锁定不会被这项操作自动解除；「恢复」可解锁全部。
- **统一拖拽**：拖动组或图层，在目标组中部松手即成为其成员／子组；在目标组上缘或下缘松手，则插入为同级。图层行的上半／下半用于同级插入。可将子组拖到父组边缘，移出父组并与父组同级；拖到图层列表空白处则移到顶层。插入线／高亮显示有效落点，不能把组放入自己或自己的后代。每次完成拖拽记为一步撤销。

## 常用快捷键

Windows/Linux 用 Ctrl，macOS 用 ⌘。顶部「快捷键」或 `?` 可在页面内查看。

| 操作 | 快捷键 |
|---|---|
| 全选 | Ctrl/⌘+A |
| 复制／剪切／粘贴 | Ctrl/⌘+C / X / V |
| 原位粘贴 | Ctrl/⌘+Shift+V |
| 创建副本 | Ctrl/⌘+D（副本在原图层紧邻上方，含组内原位） |
| 删除所选 | Delete / Backspace |
| 微调 1px / 10px | 方向键 / Shift+方向键 |
| 下移／上移一层 | Ctrl/⌘+[ / ] |
| 置底／置顶 | Ctrl/⌘+Shift+[ / ] |
| 撤销／重做 | Ctrl/⌘+Z / Shift+Z，或 Ctrl/⌘+Y |
| 保存并应用 | Ctrl/⌘+S |
| 适应窗口／100% | Ctrl/⌘+0 / 1 |
| 放大／缩小 | Ctrl/⌘++ / − |
| 平移视图 | 空格+拖动／中键拖动 |

多选时，移动、复制、删除和调层级作用于整个选择，保留内部相对位置和层序。鼠标拖动和方向键长按分别记为一步撤销。

复制粘贴目前用于当前页面；普通粘贴逐次偏移 10px，原位粘贴不偏移。文字、蒙版和素材设置一起复制。输入框、可编辑文本、弹窗和输入法组合输入保留自身键盘操作。
