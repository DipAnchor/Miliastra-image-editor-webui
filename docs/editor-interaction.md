# 多选、鼠标与快捷键

[返回使用指南](README.md)

## 选择图元

- **单选**：直接点图元或图层。普通点击未选图元会替换原有选区（包括此前选中的组），后续删除只针对新选区。
- **增选／减选**：画布上按 Shift 或 Ctrl/⌘ 点选。
- **连续选择**：图层列表按 Shift 点选，以最近单击的图层为起点；Ctrl/⌘ 切换单项。
- **框选**：在空白处拖框，碰到图元范围即选中；按 Shift/Ctrl/⌘ 可追加。
- **选择分组**：点击分组会同时选中组内全部元素（含嵌套子组）；Ctrl/⌘ 或 Shift 点组可增选／减选，也可与单独图层混选。右键已选项保留当前混合选择；删除或创建副本会一次处理选中的组和组外散层，重叠选中的父子组不会重复处理。
- **取消**：点空白处或按 Escape。拖动途中按 Escape 会恢复操作前状态。

画布从上往下命中鼠标所在位置的可选内容。自身或祖先组锁定的图层会被跳过；形状空洞、可读取贴图中的透明像素及被蒙版裁掉的位置也会穿透；没有命中时按空白处理。普通模式只移动图元，不显示缩放点、锚点或旋转控件；拖动任一已选图元可整体移动，Alt 拖动会复制整个选择。

## 多选属性与右键菜单

- 多选后，右侧「图层操作」可编组、置顶、上下移动和置底；锁定区域可锁定所选、锁定其他或恢复图层。批量调层级保留所选项的相对层序。
- 在已选图元上右键，会保留整个选择并显示所选数量。菜单可批量修改填充颜色、透明度，以及操作图层、锁定和显隐；不显示单个图元的宽高或旋转输入。在未选图元上右键则切回该图元的单选菜单。
- 菜单的 ±10% 按钮围绕未锁定所选图元的整体包围盒中心缩放，尺寸、位置和间距同步改变；智能对象仅缩放外壳，旋转角和内部内容保持不变。每次点击直接生效并可一步撤销，不进入变换编辑；缩小受最小尺寸限制时使用统一比例。
- 多个颜色或透明度不一致时显示「混合」。批量改色和透明度跳过锁定图层；文本框同步文字颜色或文字透明度。智能对象的透明度仅修改外壳，填充颜色不批量改写其内部内容。每次批量操作可一步撤销。

## 变换模式

在画布上方点击「变换」，或按 Ctrl/⌘+Alt+T，当前选择会显示八个方形缩放点与一个可拖动锚点，单图元、多选和整组使用同一套操作。准备状态仍可更换选择，并可再次按快捷键退出；拖动任一缩放点、锚点或框外旋转圈后，进入变换编辑并锁定当前目标，需先应用或取消才能切换模式。单独移动图层不进入变换编辑。

- 拖动八个缩放点改变尺寸；默认固定对边或对角。开启「中心」后，固定可拖动锚点，以该点为中心缩放。
- 拖动锚点改变旋转与中心缩放的基准位置。锚点仅用于当前变换，不写入作品数据。
- 准备状态下，拖动框内区域直接整体移动，松手即生效并形成一次撤销，无需应用；已进入变换编辑时，框内移动仍属于当前预览。框外沿选框宽、高各向外延伸约 20% 的窄圈内可旋转，没有单独的旋转手柄。窄圈内显示双向弧形箭头，开口始终朝向当前锚点；更远处恢复普通选择操作。旋转一旦开始，拖动可超出窄圈，直到松开鼠标。
- 「自由」关闭时，角点缩放保持宽高比例，边中点仍按单轴缩放；智能对象始终保持正向等比缩放。吸附、网格和角度步长继续生效，旋转时按住 Ctrl / ⌘ 临时忽略角度步长。
- 点击「应用」或按 Enter 一次性提交本轮变换；点击「取消」或按 Esc 丢弃本轮预览。多次拖动、方向键微调及属性数值修改只形成一次撤销；仅移动锚点不增加撤销记录。
- 变换编辑期间，右侧图元属性的 X／Y、宽／高及 X／Y／Z 旋转输入仍可使用，数值实时更新当前预览，随后可继续拖动控件。多选可修改整体位置；智能对象可修改位置、Z 旋转和等比缩放。数值输入保留原有属性语义，控制框与锚点随几何更新。

变换编辑期间可继续平移和缩放视口，以及修改上述变换属性；外观、蒙版、画布和图层结构操作仍锁定，不能切换目标、增删图层或保存预览，需先应用或取消。控件大小固定在屏幕上，不随画布缩放而变大。应用或取消后仍保持变换模式，可继续下一轮调整。

## 成组、锁定与层级拖动

- **成组**：在图层面板底部点「成组」，或在图层／分组右键菜单点「编组」。选择多个组或组＋图层时，新建一个组收纳所选项，原组及其子组结构保留；新组放在最近共同祖先内。成组后选中新组，可一步撤销／重做。
- **避免重复编组**：仅选中一个已有组，或完整选中某个已有组的全部内容时，再次编组只提示「所选内容已在同一个组中」，不新增嵌套或撤销记录。选择组内部分成员仍可建立子组，已有嵌套结构不会自动清理。
- **解组保持外观**：解除分组时，原组的隐藏状态和透明度由移出的图层或子组承接，文字、背景与描边分别保留有效透明度；外层祖先组继续生效。嵌套子组及智能对象内部内容保留，每次解组可一步撤销／重做；含受保护成员的组跳过。
- **同级层序**：置顶、置底、上移、下移只调整各自父组内的完整节点；混选组与散层时，组及其全部后代作为整体移动。层级数字仍显示全局编号，但输入会落到同父级的合法边界，跨越兄弟组时整体跳过，不改变归属；跨组移动使用拖拽。到达边界或内容受锁定保护时，无变化不增加撤销记录。
- **有效锁定**：图元自身或祖先组锁定后，画布点击会穿透该图层；仍可在图层面板选中它以便解锁。手工方向键、拖动、删除、透明度修改与智能对象双击编辑均受保护。混选只修改可编辑图元，组操作若会改动受保护成员则跳过该组，保留提供锁定的祖先结构。图层不能拖入锁定组。组锁在 JSON 导入、保存和撤销／重做中保留。WebMCP 仍按其文档允许 AI 显式编辑锁定内容。
- **锁定其他**：保留所选图层、所选组及其全部后代，以及必要的祖先组；锁定其它项，不会因锁住祖先而间接锁住自己。已有锁定不会被这项操作自动解除；「恢复」可解锁全部。
- **统一拖拽**：拖动组或图层，在目标组中部松手即成为其成员／子组；在目标组上缘或下缘松手，则插入为同级。图层行的上半／下半用于同级插入。可将子组拖到父组边缘，移出父组并与父组同级；拖到图层列表空白处则移到顶层。插入线／高亮显示有效落点，不能把组放入自己或自己的后代。每次完成拖拽记为一步撤销。

## 作品、历史与迟到导入

- 打开另一份作品会建立独立的撤销／重做历史，不会撤销回上一份作品的内容。关闭启动恢复后，空白画布使用新作品身份，保存不会覆盖此前打开的作品。
- 恢复快照同时保存作品身份和内容；新建、打开或另存为后立即刷新也不会串用上一份作品。旧版没有身份信息的恢复快照保留内容，并作为新作品恢复。
- 对当前作品「另存为」会复制当前实时编辑内容；复制列表中的非当前作品则使用那份作品已保存的快照。读取待导入文件只填充导入来源，不提前修改当前作品名称。
- 手工导入或 WebMCP 导入等待响应期间，如果新建／打开作品、编辑、撤销／重做，或进入对象／变换编辑，则旧响应作废并提示重新导入；即使编辑后撤销回相同内容，也不会接受旧响应。上下文未变时，普通导入仍可一步撤销／重做。
- 拖动期间若有外部场景提交或执行撤销／重做，会终止旧拖动；后续鼠标移动、松手或 Escape 不会回放旧图层、丢失新增图层或撤销新锁定。粘贴、拖入收藏对象或清空选区时，会同步替换图元和组选区，删除只作用于当前选择。

## 常用快捷键

Windows/Linux 用 Ctrl，macOS 用 ⌘。顶部「快捷键」或 `?` 可在页面内查看。

| 操作 | 快捷键 |
|---|---|
| 全选 | Ctrl/⌘+A |
| 复制／剪切／粘贴 | Ctrl/⌘+C / X / V |
| 原位粘贴 | Ctrl/⌘+Shift+V |
| 创建副本 | Ctrl/⌘+D（副本在原图层紧邻上方，含组内原位） |
| 删除所选 | Delete / Backspace |
| 微调 1px / 10px | 方向键 / Shift+方向键 |
| 下移／上移一层 | Ctrl/⌘+[ / ] |
| 置底／置顶 | Ctrl/⌘+Shift+[ / ] |
| 撤销／重做 | Ctrl/⌘+Z / Shift+Z，或 Ctrl/⌘+Y |
| 保存并应用 | Ctrl/⌘+S |
| 适应窗口／100% | Ctrl/⌘+0 / 1 |
| 放大／缩小 | Ctrl/⌘++ / − |
| 平移视图 | 空格+拖动／中键拖动 |
| 垂直滚动视图 | 滚轮 |
| 水平滚动视图 | Ctrl+滚轮 |
| 以鼠标位置为中心缩放 | Alt+滚轮（25%–400%） |
| 切换变换模式 | Ctrl/⌘+Alt+T |

多选时，移动、复制、删除和调层级作用于整个选择，保留内部相对位置和层序。鼠标拖动和方向键长按分别记为一步撤销。

复制粘贴目前用于当前页面；普通粘贴逐次偏移 10px，原位粘贴不偏移。文字、蒙版和素材设置一起复制。输入框、可编辑文本、弹窗和输入法组合输入保留自身键盘操作。
