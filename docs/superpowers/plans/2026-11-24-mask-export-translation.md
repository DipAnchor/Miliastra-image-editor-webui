# 蒙版默认类型与 GIA 转译

目标：修复默认蒙版类型导致智能对象缩放展平失败，并在已有模拟器 codec 字段证据范围内实现客户端容器节点 GIA 的逐图元蒙版转译。素材组 GIA 保持拒绝活动蒙版；真机验证单独记录。

## 默认类型

在可见智能对象叶子进入缩放检查前，按活动蒙版素材 ID 查询元数据并缓存。只解析缺省类型，返回私有副本；无边框解析 basic，非零边框解析 stretch，缺失元数据明确拒绝。原场景与编辑快照不变。

回归覆盖默认普通素材、九宫格拒绝、显式类型、隐藏与未缩放对象、重复 ID 缓存、源数据与 Lua 回导。运行后端 unittest 全量并只读验证指定原稿导出。

## GIA 协议证据门

客户端容器节点与素材组是独立协议。当前容器节点实现依据模拟器 codec 和独立字段解码：透明图片父控件裁切内容图片子控件，支持蒙版 Basic／Stretch、反向、Pixel／Percentage 原生参数、偏移尺寸与完整旋转姿态补偿；可嵌套在画布矩形遮罩下。默认蒙版类型在绘制副本按蒙版自身元数据解析，无值／零边框为 Basic，非零为 Stretch，缺失元数据明确拒绝。

素材组目前仅有组级裁剪组件证据，没有据此实现逐图元蒙版；继续整次拒绝活动蒙版。CSS／SVG／PNG 的限制不变，prefab 仍 Lua-only。不得全局从 `BLOCKED_DRAWING_FORMATS` 移除 `container-node`；仅给活动蒙版单独声明条件支持。
