# Photopea 风格变换模式实施计划

## 目标

将当前直接实时变换改为显式变换模式：普通模式只移动并隐藏变换控件；变换模式显示八向手柄和可移动中心锚点。手柄调整和框外旋转先进入临时预览，目标选择保持锁定，应用提交一次主撤销，取消恢复进入编辑前状态。

## 范围与约束

- 目标是当前完整选择，支持单层、组和多选；编辑期间不能切换目标。
- 默认缩放固定反向边/角；中心缩放开启后以可移动中心锚点为固定点。
- 框外拖动旋转，旋转与中心缩放共用中心锚点；不显示旋转手柄。
- 保留现有缩放比例、吸附、智能对象限制和未提交的 styles.css 单圈描边修复。
- 不修改后端、导出协议或持久化锚点字段；不自动提交/推送。

## 实施阶段

1. 新增纯几何模块与测试：八方向、旋转框逆投影、中心锚点、等比/最小尺寸、非有限输入和角度归一化。
2. 在 App 中加入变换事务状态：基线场景、预览场景、目标选择、应用/取消；应用一次主撤销，取消不写历史；编辑期间锁定目标并阻止切换/普通快捷操作。
3. 重做变换 UI：八个手柄、中心锚点、变换模式入口及应用/取消控制；移除旋转手柄，框外拖动旋转；增加中英文文案与稳定屏幕尺寸样式。
4. 补纯逻辑和 App 回归：模式显隐、八向缩放、中心/非中心锚点、框外旋转、锁定、取消、应用/撤销/重做、多选和组。
5. 更新 docs/editor-interaction.md；运行前端全量测试、构建和浏览器验收；保留并复核既有 styles.css 改动。

## 验收

- 普通模式无变换 UI，仍可移动图层。
- 变换模式显示八向方点与中心锚点，控件在 100%/400% 保持屏幕尺寸。
- 普通缩放固定反向边/角，中心缩放固定中心锚点；框外旋转绕中心锚点。
- 编辑中只能操作目标，取消完全恢复，应用只增加一条主历史；撤销/重做正确。
- npm.cmd run test:all 与 npm.cmd run build 通过，浏览器交互实际验证。
