# 智能对象 UX/UI 场景与修改地图

> 2026-11-18 · 分阶段实施中，本文记录 UI 规格，完整页面闭环尚未接入。关联：[技术调研](./2026-11-18-smart-objects-research.md)。
> 已确认：普通组可转换；不连续图层先编组再转换；内部编辑隔离外部场景；解除为同一父级下的普通组；暂不按内容禁用整体变换；内部保存智能对象；有变化的保存／完成时适配画框、编辑中不实时；嵌套暂不开放，列入待做清单。

## 1. 场景—界面—改动矩阵

| UX 场景 | 需要的 UI 内容 | 状态及边界 | 接入位置 |
|---|---|---|---|
| 普通多选/选组 | 右键“转换为智能对象”；保留普通编组 | 同一父级的连续图层或一个完整普通组可直接转换；右键未选项先明确目标 | LayerContextMenu、App 选择/组菜单 |
| 转换成功 | 专属缩略图角标、对象名、一行对象图层、一套手柄 | 保持选中；状态栏成功提示；一次撤销 | App 图层行/画布、layerTree、styles |
| 不连续图层 | 提示“先编组，再转换为智能对象” | 显式编组后转换，不在转换时暗中重排或部分转换；普通组可直接转换 | 菜单、现有编组动作 |
| 外部单选对象 | 属性标题“智能对象”；X/Y、统一比例、Z、只读画框与派生 W/H、编辑内容、解除 | 不显示内部颜色/文字/蒙版；继承显隐/锁定；没有手动画框尺寸入口 | App 属性/快捷编辑/画布工具条 |
| 对象与普通层混选 | 公共变换属性、选中数量、受限操作说明 | 不显示单对象编辑按钮；禁止从批量自由缩放绕过限制 | App 多选变换、工具条 |
| 隐藏/锁定对象 | 沿用眼睛、锁标记；锁定时内容编辑按钮禁用 | 内部原始状态不改；普通用户与 WebMCP 原有锁定契约分别保持 | 图层行、菜单、命中判定 |
| 进入内部 | 面包屑、当前对象名、完成/取消、未应用修改标记 | 图层树/属性/新增内容切到当前作用域；恢复原主场景视口 | 新 EditBar、编辑会话状态、App |
| 内部正常编辑 | 复用图形库、图层、属性、撤销/重做；显示内部坐标范围 | 操作仅作用于对象草稿，不影响外部场景；画框稳定、不实时适配，溢出不裁剪 | 当前作用域选择、画布/图层渲染 |
| 嵌套智能对象 | 首版不开放创建或多级编辑入口 | 列入待做清单 | 后续编辑作用域栈 |
| 完成应用 | 完成按钮；成功状态；返回并选中对象壳 | 无修改直接返回；有修改按全部叶适配并补偿位置，主历史加一步；验证失败留在草稿 | 编辑会话、commitScene |
| 取消/跳转 | 无修改直接退出；有修改应用/放弃/继续编辑三态弹窗 | Esc 不直接丢弃；弹窗取消回编辑；恢复焦点 | 新 LeaveSmartObjectDialog、统一离开守卫 |
| 复制/删除 | 复用 Ctrl+D、Delete、底部按钮和菜单 | 副本独立；改副本不改原件；删除不自动解除 | 复制/删除命令及纯逻辑 |
| 解除 | “解除为普通组”；短说明“保留当前外观” | 留在同一父级；完整单根组直接复用、不加深层级，多个根组或散落图元才包装；保留真实子组，合并对象名称及透明度／显隐／锁定；选中结果组；失败原子回退 | 对象菜单、属性、smartObjects |
| 内部保存 | “保存并继续编辑”（Ctrl+S） | 有变化时适配全部叶（含隐藏／锁定）并应用留态；一次主撤销，内部撤销/重做重基保留；空内容保留 frame，无变化不适配不提交；不触发作品存档/收藏 | 编辑上下文、快捷键路由 |
| 作品存档/导入/新建 | 标明操作目标；有草稿时走离开守卫 | 导入目标需明确；不静默保存旧主场景 | 顶栏、存档/导入/新建动作守卫 |
| 导出/代码预览 | 标明完整作品/当前对象；诊断显示对象名/内部层名 | 内部草稿导出前要求完成或取消；代码页不展示陈旧根内容冒充当前 | drawingExportScene、代码页、WebMCP |
| 重开项目 | 对象行和编辑入口恢复 | 非法/未知版本不能降级为矩形；存储失败明确提示 | archives、后端模型/JSON |

## 2. 界面内容与布局

### 图层行与菜单
- 沿用紧凑行高，不增加副标题占一整行。缩略图右下角加对象角标；眼睛和锁的位置保持不变。
- 对象外层不显示可展开子树箭头，避免用户误以为是普通组；内部内容只在编辑模式出现。
- 双击对象缩略图=编辑内容；双击名称继续使用现有重命名，不劫持整行双击。
- 对象缩略图未加载时显示稳定占位图标；生成缩略图失败不影响编辑，不要求接入位图缓存系统才能上线。
- 转换入口在普通图层/组菜单；对象菜单显示编辑内容、解除，普通组的“解组”和对象“解除”不能混用。
- 本轮核对 LayerContextMenu 当前不含复制/删除/改名行；第一版复用现有底部动作和名称双击即可，不为此顺带扩充所有普通菜单。
- 画布右键现为快捷属性面板；对象显示位置/统一比例/Z/透明度及编辑内容，不显示叶子专属颜色和蒙版。

### 右侧对象属性
建议布局：对象类型与名称 → 编辑内容主按钮 → 只读内容画框 → X/Y → Z、统一比例 → 只读派生 W/H → 显隐/透明度沿用现有入口 → 解除次操作。
- X/Y 倾转控件不作为对象可编辑属性；若保留占位需附未支持说明。
- frame 与派生 W/H 只读，没有手动画框尺寸入口；全局“自由”开关不改变对象仅正向等比缩放的能力。提示需明确有变化的保存／完成时自动适配，编辑中不实时，不裁剪溢出。
- 暂不因内部含 X/Y 倾转等内容禁用整体变换；具体导出限制仍给出诊断，不把未验证行为当成实机事实。
- 不新增外链、替换内容、共享源、滤镜等虚假入口。

### 内部编辑上下文条
建议放在画布上方、现有画布工具条之前；根顶栏仍保留作品身份，不把内部对象改名成主作品名。
示意：主场景 > 小熊    未应用修改                      取消 | 完成编辑
- 主按钮固定可见；名字过长单行省略，悬停完整路径。
- 仅内部草稿变化才显示未应用修改；视口缩放或选择不算修改。
- 进入前保存根选择/缩放/平移；返回后恢复视口并选中对象，不强制再次自动适配主画布。
- 图形库点击/拖入/快捷图形库落点、图层搜索、Solo、锁定其他、复制和 Delete 都限定当前作用域。
- 右侧画布属性若仍可见，必须标“对象内部边界”，不能编辑根画布或内部画框尺寸；不提供手动尺寸入口。编辑中边界稳定、允许溢出、不 clip。
- 有变化的 Ctrl+S／完成按全部叶（含隐藏／锁定）的几何 AABB 适配 frame；局部平移与壳 position 补偿保持编辑后内容在主场景中的视觉位置，rotation/scale 不变，但中心和外框可变。空内容保留上次 frame，无变化不适配不提交；导出协议不变。
- 内部撤销到头后禁用，不能穿透撤销根场景。保存适配后 draft/saved/past/future 与内部编辑器历史统一重基，保留撤销／重做。
- 首版不开放嵌套创建与多级编辑，列入待做清单。

### 离开编辑弹窗
标题：“小熊”有未应用修改
说明按目标动作变化，例如“应用后将返回主场景并打开导出”。
按钮：继续编辑（安全默认）、放弃修改并继续（危险样式）、应用并继续（主操作）。
- Esc/点击遮罩=继续编辑；应用失败不执行目标动作。
- 浏览器关闭只能使用浏览器原生 beforeunload 警告，不能承诺能弹自定义三按钮或退出时自动保存。
- 另存为/导出/存档都必须先明确操作的是整份作品，而不是内部子场景。
- 内部 Ctrl+S 应用当前智能对象并留在编辑态；每次有变化的保存记一次主撤销，无变化不提交。完成只提交最近一次保存后的新改动并退出；放弃不回滚已保存部分，不执行主作品收藏/存档。

### 诊断内容
统一结构：动作名称、原因摘要、对象/图层路径、建议解决办法；必要时允许定位到内部层，但定位前处理当前草稿。
错误级别分开：阻止（无法无损执行）、警告（现有格式已知限制）、信息（独立副本等）。
只有实际存在问题才显示，不让正常导出多走一次弹窗。原格式的警告/跳过政策继续沿用，不能以智能对象为由重写全部导出规则。

## 4. 状态与实施顺序

概念状态：root → editing-clean → editing-dirty → leave-prompt；保存成功回 editing-clean 并留在编辑态，完成成功回 root；放弃仅丢弃最近一次保存后的未应用修改并回 root；继续返回原草稿；应用失败留在原草稿并显示原因。
离开守卫要保留完整待执行动作及参数，不只是 new/import/export 字符串；用户作出决策前，禁止多个入口重复排队或执行两次。
所有更新保持不可变；对象草稿历史与根历史隔离；操作菜单、拖拽和键盘使用同一能力检查。

实施建议：
1. 将已确认规则写入纯逻辑/保存测试，细化内部边界与保存事务。
2. 最小 UI：图层对象行+转换入口+外部属性+基本变换。
3. 核心 UI：上下文条+内部草稿+完成/取消+统一离开守卫。
4. 兼容 UI：导出/代码预览诊断、存档导入、收藏和 WebMCP。
5. 缩略图优化后续评估；嵌套智能对象列入待做清单，不属于首版。

## 5. 验收与未决策项

验收：普通组可直接转换；不连续图层先显式编组，转换本身不重排；解除为同一父级下普通组，保留内部组织且不部分失败；缩略图双击进入，名称双击仍改名；内部撤销不穿透；Ctrl+S 应用并留在编辑态，每次变化一次主撤销；完成仅提交保存后的新改动并退出；放弃不撤销已保存部分；含 X/Y 倾转不自动禁用整体变换；首版不开放嵌套；离开入口不绕过草稿保护；应用失败不执行后续动作；复制独立。
可访问性：按钮可 Tab 到达；禁用理由不是只靠 hover；状态不只靠颜色；面包屑有可访问名称；Esc 不丢草稿；面板窄宽度不遮挡完成按钮。
已确认：普通组可直接转换；不连续图层先编组再转换；内部操作隔离外部场景；解除成普通组并留在同一父级；暂不按内部内容禁用变换；内部保存智能对象。
边界规则已确认：保存时适配而非实时、空内容保留 frame、无变化不适配、溢出不 clip、内部历史重基保留；保存与完成关系见内部保存与状态章节。正常解除是否二次确认仍待细化。
待做：嵌套智能对象（创建、多级导航、分层草稿事务）。
本文为交互规格；实现与验证进度见技术调研，不代表全部 UI 已完成。
