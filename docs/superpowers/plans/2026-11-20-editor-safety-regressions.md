# 编辑器高风险回归与修复计划

> 执行授权：用户要求先补失败回归，再修存档身份、选区、锁定，并验证相邻操作。只修改本计划范围；不提交、推送，不自动清理已有分组，不扩展导出协议。

## 完成标准

作品保存身份不能与内容跨作品串用；迟到导入不能覆盖已经切换或修改的作品；操作目标必须等于当前真实选区；手工编辑不得绕过自身或祖先组锁。正常导入和批量编辑保持一步撤销。
