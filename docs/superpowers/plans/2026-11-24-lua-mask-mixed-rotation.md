# Lua 旋转蒙版与混合倾转补偿

**目标：** 核查旧导出保护，使用完整局部旋转补偿，使活动旋转蒙版可与内容 X/Y 倾转组合导出。保持纯 Z、编辑快照、蒙版参数和控件数量。

**方法：** 按当前编辑器 Z-X-Y 约定，父蒙版为 Rz(m)，子控件需 Q=Rz(-m)Ry(Y)Rx(X)Rz(Z)。从完整三维矩阵分解 Euler，处理奇异点；不能只将 Z 减去蒙版角。

**证据边界：** 官方 SetLocalRotation 接口未声明混合 Euler 顺序。数学与 Lua VM 测试证明编辑器约定下等价，不代替真机。默认蒙版类型解析、GIA 蒙版转译不在本次范围。

## 实施步骤

1. 独立审查矩阵与布局，核实官方 API 和既有真机证据。
2. 在 backend/app/rotation.py 实现补偿并测试纯 Z、整圈、奇异点、随机样本、原袖口样本。
3. 在 backend/app/lua_scene.py 生成派生姿态表，在 backend/app/lua_mask.py 应用；源绘图表原样保存。
4. 将 backend/tests/check_textbox_lua.cjs 扩展为完整三维姿态对比，覆盖图片、文本、锚点、负缩放与清理。
5. 运行完整后端、前端逻辑和类型检查，原作品只读 API 对照；同步指南、维护说明和 WebMCP 能力描述。

**验收：** 原拒绝组合可导出并回导；父子姿态矩阵相同；纯 Z 和蒙版生命周期回归通过；原作品文件哈希不变。原稿若仍受默认蒙版类型解析阻塞，单独报告，不修改原件。
