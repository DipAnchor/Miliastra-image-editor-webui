# 使用指南

[中文首页](../README.zh-CN.md) · [English](../README.md) · [在线编辑器](https://qx.070077.xyz/)

## 创建与保存作品

1. **添加内容**：图形库拖入或双击添加。素材可按分类、用途、关键词检索；元件按准确 ID 查询。
2. **编辑**：画布拖动，单选使用缩放／旋转手柄；右侧「图元」设置文字、颜色、位置与层级。「高级」设置 Lua 蒙版和羽化。
3. **多选**：Shift 点选增减，空白拖框选择；多选后可整体移动、复制、删除和调层级。
4. **保存**：导出 JSON。下次从「导入」打开即可继续。撤销历史和当前选择只保留在本次会话。
5. **历史存档**：工具栏「历史存档」把整份画布存到浏览器本地（默认最多 20 个，可在「设置」调整），支持打开、另存为、删除；手动改文档名会同步存档名，身份按画布 ID 区分，当前正在编辑的存档行名前显示红点。

「保存并应用」把当前图元更新到可复用图形库，并刷新代码预览；它不会下载文件或自动保存到服务器。

## 图元复用与收藏

图形库中已保存的图元属于当前作品，随作品 JSON 保存；画布右键快捷素材库中的「收藏」保存在当前浏览器，可跨作品使用，不随作品 JSON 导入或导出。

- 收藏已保存图元时，会固定当时的名称和内容。以后修改或删除源图元，不会更新已有收藏；要更新内容，请取消后从原图元重新收藏。不同作品中的同名图元分别收藏，不会互相替换。
- 点击或拖入收藏会添加独立副本，放到当前画布顶层。智能对象副本的内部图层和组同样独立；图片和元件仍依赖对应外部素材资源，收藏不会打包素材文件。
- 旧收藏如果没有保存内容，会保留名称和取消收藏入口，但不能添加或拖入。请从明确的原图元重新收藏，不会自动用当前作品的同名图元补配。
- 若提示收藏已在本会话更新但未能保存，本次更改仍可在当前会话使用，刷新后可能丢失；原持久收藏保持不变。后续收藏更改成功保存后，该提示才清除。

## 让 AI 整理图层组

浏览器接通 [WebMCP](webmcp.md) 后，可让 AI 在拼搭定稿后按部件一次创建命名嵌套组，例如「火史莱姆 → 身体／角／眼睛」。AI 先读取当前图元和组 ID，再调用 `create_layer_groups`；成功的一批只占一步撤销，组名随作品 JSON 保存。也可以在已有组下新建子组，原有隐藏与透明度继续生效。

工具只收同一接入父级下的直属普通图元，要求每个新组及子组在原层序中各自连续，隐藏图层也参与检查；不会自动调整层序。成员或祖先锁定、成员跨父级、交错或无效输入时整批拒绝，原画布保持不变。现有组的移动／改名、智能对象内部组织仍使用相应编辑器入口。参数示例和错误处理见 [一次创建命名嵌套组](webmcp.md#一次创建命名嵌套组)。

## 独显与恢复显示

右键图层选择「只显示自己」，或右键组选择「只显示本组」；「恢复显示」恢复该次独显前的显隐状态，包括原先隐藏的内容。独显、恢复显示及其恢复依据一起参与撤销／重做；即使画面未变化，进入或退出独显也可撤销。

独显恢复依据只保留在当前编辑历史中。JSON 和本地存档保存当时的显隐值，不保存独显前的快照；刷新、新建或重新打开作品后，不会沿用旧作品的「恢复显示」状态。

## 智能对象

智能对象把可编辑内容打包为一个外层图层，不是位图，也不是与原件联动的共享实例。

1. **转换**：右键普通组，或同一父级下连续选中的普通图层，选择「转换为智能对象」。不连续或跨父级图层请先显式编组，再转换；转换本身不暗中重排。组内的图层组织、隐藏与锁定状态随内容保留。暂不支持嵌套智能对象。
2. **外部变换与复制**：对象可整体移动、Z 旋转、正向等比缩放和调整不透明度；宽高由当前画框 × 比例派生，不支持非等比或负向缩放，没有手动画框尺寸入口。复制得到独立内容，编辑副本不改变原件。
3. **编辑内容**：双击图层列表中的对象缩略图，或选择「编辑对象内容」，进入独立局部草稿；双击图层名称仍为重命名。草稿复用图层和图元编辑，撤销／重做不穿透主场景。编辑中画框保持稳定，不实时适配，允许内容溢出，画框本身不裁剪内容。
4. **保存与退出**：「保存并继续编辑」或 `Ctrl/⌘+S` 只应用当前对象并留在编辑态，不触发主作品收藏／存档。有变化时按全部图层（含隐藏／锁定）的几何轴对齐包围盒适配画框，并平移局部坐标、补偿对象位置，保持编辑后内容在主场景中的视觉位置；对象旋转和缩放不变，但中心与外框可变。每次变化记一次主撤销，内部撤销／重做重基后保留；空内容保留上次画框，无变化不适配、不提交。「完成编辑」只按同一规则应用最近一次保存后的新改动并退出；没有新改动直接返回。「放弃本次修改」仅丢弃最近保存后未应用的草稿，不回滚已保存内容。「返回主画布」有未保存修改时可选保存并退出、放弃或继续编辑。要保存整份作品文件，返回主画布后导出 JSON。
5. **解除**：「解除为普通组」把当前外层变换映射到子图层，保留当前父级归属和内部组织，不是回到打包前的位置。内部只有一个完整根组、没有散落图元时，直接复用该组，不增加层级；对象名称与透明度／显隐／锁定合并到该组，真正的内部子组保留。多个根组或散落图元才新建普通组收拢。无法精确表示时会阻止操作并指出对象／内部层，不能强行近似解除。

**保存与导出边界**：JSON 保留对象壳、内部内容、组和隐藏／锁定数据；其它绘制出口先展平为普通图元，再沿用原格式限制。Lua 的运行绘图数据同样展平，完整对象另存于带绘图摘要的编辑快照；回导时摘要匹配才恢复对象，外部修改绘图记录后会警告并按当前记录重建，不能恢复陈旧对象结构。

含 X/Y 倾转的内部内容不会预先禁用外层变换，但混合轴组合、拉伸图片缩放、蒙版变换、非整数字号或自定义文字锚点等可能无法精确展平；解除／导出时按具体诊断处理，可先保存 JSON。组与对象透明度仍沿用逐层烘焙近似，不承诺重叠处的精确整体合成。智能对象的 GIA／Lua 导出尚未真机验证。

## 导入与导出

- JSON 最适合完整保存。Lua 支持本编辑器与配套拟合工具的绘图数据；导入仅读取数据，不运行脚本。
- CSS 和 SVG 支持有限图元子集。复杂路径、滤镜、任意分组与渐变不保证还原；导入后留意警告。
- 模板格式会自动识别（JSON / CSS / SVG / Lua），无需手动选择。
- 欢迎页与工具栏的「导入」都打开同一个导入窗口，可选择「覆盖当前画布 / 追加到当前画布」；取消不会改变作品。追加会为导入的分组与图元重新分配 id，并叠加在现有内容之上。导入内容为空时会提示，不会清空画布。
- GIA 用于界面素材组。导出菜单的「容器节点 GIA」生成客户端控件模板：每个图片类图元成为容器的图片子控件，无需 Lua；文本框、元件和圆形画布遮罩暂不导出。Lua 可绘制图片、元件和原生文本框，使用前按[说明](lua-mask.md#使用导出的-lua)配置模板索引。
- 含元件或已启用图元蒙版／羽化的作品只能保存 JSON 或导出 Lua。辅助虚线不导出。
- SVG 是有限子集：例如圆环会省略，图片染色也可能产生提示。代码预览展示本次全场景响应的全部导出提示；下载时展示该文件的全部提示。单图层下载的提示只对应所下载的内容，不替换全场景预览。需要完整保存作品时用 JSON，或按图元能力选择 Lua。
- PNG 可通过 `/api/export/png` 或 WebMCP `get_canvas_preview` 获取；网页导出菜单主要提供 GIA、容器节点 GIA、Lua、CSS、SVG、JSON。

在画布编辑区内，普通滚轮垂直滚动，Ctrl + 滚轮水平滚动；Alt + 滚轮以光标位置为中心缩放，向上放大、向下缩小，范围 25%–400%。智能对象内部画布同样适用；图层、属性和工具栏保留自身滚动。按住空格拖动或中键拖动仍可平移视图；工具栏缩放、100% 和适应窗口功能保留。

画布查看背景、缩放倍率及辅助线不改变作品，也不增加撤销记录。需要实色背景时添加满画布矩形。画布级 GIA 遮罩与图元级 Lua 蒙版是两套设置，不能互相替代。

## 常见问题

**刷新后作品不见了？** 当前画布不会保存到服务器；但手动「保存并应用」会在工具栏「历史存档」生成存档，可在「历史存档」里打开对应存档继续。为长期保存仍建议导出 JSON。

**选中了图片却看不出基础／拉伸区别？** 调整图元宽高试试；接近原图大小时两者可能相同。只有带切片边框的素材提供拉伸。

**蒙版开了但辅助画面仍看得到全部内容？** 「显示蒙版辅助预览」保留原内容，灰色半透明覆盖表示被遮部分，细虚线标出轮廓。关闭它可看实际裁切。

**反向蒙版为什么没有显示矩形框外的内容？** 反向只翻转蒙版范围内的图片轮廓，范围外仍裁切；旋转时范围一起旋转。该语义已按真机样本修正，但羽化与边缘采样仍为预览近似。

**倾转后图元消失？** X/Y 为 90° 时侧立。可从图层列表选择，再修改角度。

**素材无法加载？** 点击图形库刷新；确认可连接素材服务。已有画布和基本图形仍可编辑。
