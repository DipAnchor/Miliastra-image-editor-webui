# Lua、容器节点 GIA、蒙版与羽化

[返回使用指南](README.md)

## 使用导出的 Lua

1. 在千星编辑器准备干净的客户端控件模板，并设为“仅存为模板”。图片或蒙版需要图片控件；文字需要文本框。
2. 在本工具选择「导出 → Lua」，或「复制 Lua 绘制脚本」。填写脚本顶部的真实模板索引：

   ```lua
   local IMAGE_PREFAB_ID = 0   -- 图片控件模板索引
   local TEXTBOX_PREFAB_ID = 0 -- 文本框模板索引（含文字时）
   ```

3. 在游戏编辑器建立脚本映射，将脚本挂到**专用空客户端容器节点**。脚本启动时自动创建图元；不要挂在会被实例化的模板上。
4. 保存并试玩，检查文字、层级、素材和蒙版效果。

`0` 表示尚未配置，不能直接使用。素材图片 ID、元件 ID 与控件模板索引是不同编号。脚本会设置宿主的尺寸和变换，因此应使用专用容器。

Lua 支持图片与原生文本框。纯文字且没有蒙版时无需图片模板。元件 ID 保存在脚本的 `PREFAB_IDS` 表中，无需另建同名客户端脚本参数。

导出的 Lua 可以重新导入编辑；请保留末尾编辑器数据注释。导入只读取支持的绘图数据，不执行脚本，也不还原任意游戏逻辑或运行时动画。

## 设置蒙版

选中图元 → **图元 → 高级**。

| 设置 | 用法 |
|---|---|
| 蒙版图片 ID | 默认 `100001` 矩形；`100002` 为圆形。点击缩略图打开选图面板，也可手填 ID 后按 Enter |
| 图片类型 | 保持默认、基础、拉伸；可选类型共用图形库的素材边框判断 |
| 启用蒙版 | 仅保留蒙版覆盖的内容 |
| 区域反转 | 只在旋转后的蒙版外框内交换保留与遮住的区域；框外仍裁掉，不是对整个画布取反 |
| 偏移 X/Y | 相对原图元中心；X 向右，Y 向下 |
| 尺寸跟随图元 | 不单独指定宽高；手填 `0` 表示零尺寸 |
| 羽化 | 让边缘逐渐透明；开启羽化也会使用蒙版 |

选图时可按 ID、名称、用途搜索，或使用六种形状快捷按钮。选中候选会临时预览；「使用此蒙版」保存图片和类型，取消恢复。换到不支持拉伸的图片时，显式拉伸调整为基础；Lua 普通图元的“保持默认”沿用原生类型，容器节点 GIA 的默认类型按蒙版自身素材解析，见下文。

**蒙版作用于当前图元。** 导出会创建一个透明图片父控件，把原图元挂在它下面；项目的图层列表不会新增父子层级。

### 在画布上编辑蒙版

在「图元 → 高级」点击 **编辑蒙版**。拖框内或中心点移动，拖边点或角点缩放；将指针移到边框外侧，出现旋转光标后拖拽，即可绕蒙版中心旋转。方向键微移，按住 Shift 加快；拖角时按住 Shift 可保持比例。

拖动蒙版时，主画布和右侧蒙版范围预览同步显示草稿，右侧预览保持正常亮度。编辑中可随时切换「显示蒙版辅助预览」：开启时显示轮廓和半透明遮挡，关闭时显示实际裁切。「区域反转」也可随时切换，两处预览会立即更新，反转设置随草稿一起应用或取消。其它图元、图层、属性和菜单保持锁定。点 **应用**（Enter）保存为一步撤销，点 **取消**（Esc）恢复原状。编辑蒙版不改变原来的启用状态。

在普通「变换」模式中，控制框仍对应图形本体，启用的蒙版随图元移动和旋转。拖动缩放边时，蒙版中心跟随图形变化，宽高按图形本地的横纵缩放比例更新，保留相对角度，不把蒙版剪切成斜四边形。无法表示的倾转或退化投影仍保留上一次有效预览。

通过 WebMCP 更新宽高和旋转属于直接改字段，不会自动执行这套整体变换。需要同步修改时，可在同一请求中提交图元与蒙版的目标值，见 [WebMCP 更新示例](webmcp.md#通过工具更新图元与蒙版)。

## 看懂辅助预览

「显示蒙版辅助预览」默认开启：

- 原内容保持可见。
- 细虚线标出蒙版轮廓，圆环同时标出内外边界；放大画布时线宽保持轻细。
- 半透明素材按各独立图案的相对透明度提取辅助外形，避免固定阈值造成假缺口；实际裁切仍使用原图透明度。
- 灰色半透明覆盖表示被遮区域，羽化和反转也会反映在覆盖上。
- 关闭辅助显示，查看实际裁切画面。

独立蒙版小图中，白色表示保留，透明表示裁掉，绿虚线是原图元范围。辅助显示只用于编辑当前选中图元，不写入作品或导出；选择候选也不会提前修改场景。

## 羽化怎么调

**像素模式（Pixel）**：水平宽度控制左右，垂直宽度控制上下；`0` 为该轴硬边。矩形与椭圆的真机单轴样例显示，衰减沿蒙版外框的横纵方向叠加在图片透明轮廓上，不沿每一条轮廓边缘等宽羽化。例如 X=24、Y=0 只影响左右外框附近，椭圆顶部仍可保持硬边。网页当前仍按轮廓近似，不能作为精确真机效果。

**百分比模式（Percentage）**：真机校准的横／纵范围均为 0、50、100 时，分别表现为硬边、向中心聚集的柔边和更强衰减；100／100 样例中心有效 alpha 约 25%，边缘接近透明。范围增大时衰减增强。网页当前沿用相反方向的旧近似，尚未校准；不要依照网页结果反向修改要导出的数值。矩形 UV 两轴的 smoothstep 衰减相乘可解释已测样例，但尚不能推定所有素材与参数的完整原生公式。

切换模式会保留另一模式的数值，可展开“另一模式的原生参数”查看。JSON、Lua 和容器节点 GIA 保存原值，包括显式的 `0`。

## 保存与限制

- 启用蒙版或羽化的作品可保存 JSON、导出 Lua；由六种基础形状和图片组成、能精确展平的内容还可导出**容器节点 GIA**。文本框、元件和 `other` 仍不支持容器节点出口。素材组 GIA、CSS、SVG、PNG 继续拒绝活动蒙版。
- 智能对象缩放展平时，活动蒙版的“保持默认”在绘制副本中按自身素材边框解析：无边框为基础，有边框仍按拉伸处理并拒绝不可精确缩放的组合；元数据缺失时明确报错。源作品、JSON 和 Lua 回导快照保留默认值。
- 蒙版角度以自身中心为轴，逆时针为正。旋转蒙版可与内容 X/Y 倾转组合导出 Lua 或容器节点 GIA：按编辑器 Z-X-Y 旋转约定计算子控件完整局部姿态，补偿蒙版父控件旋转。Lua 回导保留原始角度；容器节点 GIA 的 X=25°、Y=-40°、Z=70° 与蒙版 Z=37° 的缩小样例已在真机校准，其它角度、控件类型和 Lua 运行效果不由此推定。
- 完全关闭效果需同时关闭「启用蒙版」和「羽化」；任一开启都使用蒙版。
- `get_canvas_preview` 不是网页截图，也不能用 JPEG 绕过 PNG 导出限制。有活动蒙版时请在网页画布关闭辅助显示，查看裁切结果。
- 基础形状按编辑器几何预览，其它图片按透明轮廓与切片预览。已有真机样本显示反转时外框外仍裁掉，以及 Pixel 羽化可产生渐隐；这不验证精确的渐隐曲线、Percentage 模式或所有素材与参数组合。
- 图片加载失败时显示原内容及提示；可重试。网页或模拟器的结果不能替代目标关卡的真机验证。

## 容器节点 GIA 的蒙版

在导出菜单选择「容器节点 GIA」。每个活动图元蒙版生成透明图片父控件，内容图片成为其子控件；启用羽化也会启用父控件裁切。支持蒙版基础／拉伸类型、区域反转、Pixel 与 Percentage 原生羽化字段，以及偏移、尺寸、旋转与内容倾转的姿态补偿。画布矩形遮罩可继续包在这些图元外层；圆形画布遮罩仍不支持。图元蒙版的图片轮廓与画布遮罩形状是不同设置。

容器节点 GIA 会在绘制副本中按**蒙版自身**的素材元数据解析“保持默认”：边框值缺省或全零为基础，任一边框非零为拉伸；素材元数据缺失时明确拒绝。它不会读取内容图片的边框代替蒙版，也不会改写源作品、JSON 或 Lua 回导快照中的默认值。智能对象缩放时仍会拒绝无法精确表示的拉伸蒙版组合。

客户端容器节点 GIA 已完成两轮真机样例校准：硬边、边界内反向、单独 Z 轴旋转，以及 Pixel 单轴与 Percentage 0／50／100 均能显示原生效果。导出中的显式零值在真机正确生效；与网页、模拟器羽化外观的差异不应通过改写 GIA 参数消除。

第二轮混合倾转样例中，无逐图元蒙版、蒙版父控件 Z=0° 和 Z=37° 的大图轮廓完全一致；缩小为 40% 的无蒙版与椭圆蒙版样例分别与模拟器轮廓重合超过 99.6%。大图同样出现额外斜切边，符合该样例的固定深度边界线索，但原生裁切机制与通用阈值尚未证实。现有补偿保留，不因这条边改写旋转顺序或导出尺寸。

容器节点导出显式保留羽化宽度与范围中的 `0`。当前模拟器回导链路会丢掉这些浮点零并补成宽度 8／范围 85，其截图不能作为零参数效果的精确预期。任意素材、连续羽化曲线、其它倾转角度、嵌套组合和完整作品仍需各自验证。**素材组 GIA 尚不支持逐图元蒙版转译。**

示例：[蓝金渐变字](../demo/gradient-text.md)。它用完整蓝字叠加蒙版中的金字，共两份文字与一个蒙版；文字蒙版请使用 Lua。
